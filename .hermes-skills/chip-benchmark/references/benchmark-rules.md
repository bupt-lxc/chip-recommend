# 实测领域判定（3.0.0）

完整字段、关系键、单位和条件读取 `domain.json`。使用 MLPerf 等套件正式报告、明确硬件配置的论文/报告、厂商测试记录与社区复现。最低识别要求：具体芯片/SKU、完整模型身份、训练/推理工作负载、卡数、精度、至少一个绝对指标及单位、可区分该次测试的报告/套件与配置依据；缺任一项保存未解析候选，不计最终有效实测。来源、evidence_level、methodology 与 common source_url 分别保存。

每个指标与条件必须来自同一行/配置/报告，保留表头、脚注、引用、时间和硬件范围。总吞吐与每卡吞吐、tokens/s 与 samples/s、TTFT 与 TPOT/ITL 分开，不能凭卡数相除冒充实测。只有相对“快 3 倍”没有绝对值与单位不满足最低要求。

生成吞吐/生成时延必须明示输入长度、输出长度及 batch 或并发口径；训练指标还需对应 pretrain/finetune 工作负载、数据量/工作量、硬件卡数和配置。非生成任务不强求 token 长度，非必需条件与不适用项可 unknown/not_applicable；未知 batch 对需该条件的生成指标是 incomplete_evidence，不能设为 1。

正例：报告 R 配置 A 明确 X1 8 卡、org/model-7B、BF16 推理、输入 1024 输出 128、concurrency 16、总 3000 tokens/s，证据可定位同表和脚注，满足此指标最低要求。图像分类 X1 1 卡、完整模型、FP32、报告配置明确 100 samples/s，没有 token 长度也可有效；可选测试日期未知单独记录。例子均为假设，非实测来源。

训练正例：同报告“X1 8 卡，org/model-7B BF16 预训练 1T tokens，耗时 1000 GPU-hours”保留训练工作量、硬件范围和计算方法；精度或硬件不明确不能省略最低要求。

反例：理论峰值当 tokens/s；外推的 8 卡结果标 measured；A 配置输入长度拼 B 配置吞吐；另一型号容量/卡数移入当前报告；仅有模型系列不够完整身份；默认 batch=1/输出=128；整机/集群对象不明却计新芯片。measured、extrapolated、theoretical 分别标识与可信等级，理论/外推资料可以保留解释，不冒充实测有效计数。

程序两关与独立复核按公共参考，完整处理正文范围。条件足以支持某指标但不能唯一匹配旧记录时候选可 validated，比较 comparison_unresolved，不覆盖旧记录。历史键含型号/SKU、完整模型、suite/workload/cards/precision 和已知 batch、长度、并发、框架、硬件、日期；不同配置/运行不能折叠。库外实体用临时 ID 和依赖未解析，身份核验通过才计新芯片，不创建模型。
