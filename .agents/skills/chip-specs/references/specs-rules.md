# 规格领域判定（3.0.0）

完整字段、键、单位、条件读取同包 `domain.json`，覆盖硬件、物理形态与互联，架构/制程归本域；不由本文另列字段白名单。优先明确 SKU 的官方参数表、数据手册和架构技术文档。只接受芯片或单卡口径，建议系统电源是合同中的明确例外。

逐个 SKU/容量/PCIe/SXM/OAM 区分表列与脚注。保留原值、单位、换算、单卡口径；bit 与 byte、单向与双向、单链路与单卡聚合不可互相替换，方向或聚合未知时记 unknown。不从服务器总量除卡数推算“官方单卡规格”。制程不混封装节点，计算芯粒和 IO 芯粒的不同工艺保留适用范围，不能选择较小数字概括。

功耗区分卡 TDP/TBP、最大功耗、推荐系统 PSU；psu_w 仅保存来源针对该卡/配置的建议系统电源，并保留系统配置上下文，不能写到 tdp_w/max_power_w。实际服务器安装 PSU 总容量不是推荐值。

数值规格须绑定具体 SKU 与该值的局部来源陈述。正文其他段落仅出现目标型号，不证明当前值属于它；不能用父代际功耗替代子型号功耗。程序保守检查同一局部陈述中的 SKU/数值，或原样声明的单一 SKU 标题/表头；“均/both”等明确共同陈述可进入独立复核。混合 SKU 标题、未声明的标题或只有父代际值时保留 sku_value_binding_unresolved，不调用复核接受它，不通过身份等待补值。句段与标题检查只证明最低范围条件，比较、跨型号列值、否定和计量口径仍须语义复核，不能把词语同时出现当事实通过。

例如“某代际单芯片功耗 1300W”，后文仅说它分为 A/B，不支持 A=1300W；“A/B 两款芯片均采用 2nm”可分别复核两款制程。提取保留足以绑定主体和值的逐字引文，不向原句插入型号，不跨句拼引文。无法可靠绑定的表格/省略主语段落留未解析，不能猜列或降低校验。

数值字段的 raw_value、normalized_value 使用 JSON 数字，单位单列，例如原文 3nm 对应 raw_value=3、normalized_value=3、unit="nm"，不能返回 "3nm" 或 "3" 字符串。正文明确拆分具体变体时，共享规格逐个具体 SKU 生成候选，不合并到父代际。引文须连续包含具体变体名称和“均采用”等共同断言，不能只截取省略主体的后半句；同段相邻的父代际功耗不能因此继承给变体。

正例：X1 PCIe 64GB 一行“64 GB HBM3, bandwidth 2.0 TB/s, board TDP 300 W”可分别保存容量、2000 GB/s 换算和卡功耗；同卡安装手册明确“recommended system PSU 850 W”可记录 psu_w=850，配置范围附在证据。这里是假设例子。

反例：X1 32GB 取另一 SKU 的 64GB；八卡系统 512GB 除 8 当单卡来源；服务器 2400W PSU 写 TDP；800 Gb/s 不当 800 GB/s；“双向聚合 900 GB/s”不当单向单链路；集群网络吞吐不迁入单卡互联。表头/脚注缺失导致口径不明时保留未解析证据，不能推断。

共享身份依赖使用 identity 规则。证据、程序校验、独立复核、同页一层关联和值/来源双维比较遵守公共参考；新来源支持相同值仍保留来源候选，历史口径不明 comparison_unresolved 不覆盖。
