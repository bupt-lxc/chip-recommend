# 身份领域判定（3.0.0）

完整范围、字段所有权、实体键与日期精度均读取同包 `domain.json`。对象是明确计算芯片或板卡 SKU；不能把系列、服务器或集群当具体芯片。使用厂商产品目录、发布公告、产品页与生命周期声明；来源元数据遵守 `_shared/rules.md`。

身份厂商与型号逐字有证据，保留容量、后缀、形态和变体，实际类型 GPU/NPU/DCU/TPU/PPU/MLU/ASIC 不混写。必要时同页多个实体各自给证据、临时 ID 和行/段位置。发布、预计发布、量产、停产分别核验，保持原日期精度。明确未公开发布才使用 production_status=未公开发布 与 is_released=0；公告并不证明量产。

正例：官方正文“2026 年 9 月发布 X1 PCIe 64GB NPU”支持该 SKU 的身份、实际类型和明确发布月份；正文“该产品尚未公开发布”支持未公开状态。两者为可控例子，不能作为真实来源。

反例：页脚 Copyright 2026、文章发表日期或传闻不支持发布时间；“X 系列”不确定具体 SKU；“X1 八卡服务器”不作为新芯片；X1 32GB 和 X1 64GB 不合并。未知日期留 unknown，不按当前年份补齐。实际厂商别名/现存记录多义时 ambiguous，不能算新芯片。

身份提取和独立复核遵守公共两关流程。身份作为公共依赖复用同页快照，按 URL×完整实体线索去重；本域结果不自动扩出其他业务域。不创建模型，不写正式库。只在身份确认、基线无匹配时计 new；保持证据通过和历史可比较性分开。
