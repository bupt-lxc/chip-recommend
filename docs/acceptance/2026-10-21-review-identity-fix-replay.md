# 复核合同与 TPU 代际身份修复

本轮两处针对性修复在固定正文上起效；**仍有功耗跨变体误放行，不能宣称整体验收通过**。

- 复核请求由冻结合同生成当前字段归属提示，避免模型凭记忆删减字段。合法的 `chip_series` 正例已通过复核。
- 明确先核验具体实体，再判断字段值。来源将 TPU v8 拆分为 8t/8i 时，父代际不能作为第三颗芯片；不得继承父代际日期、功耗或换子型号解除等待。
- 修复身份登记漏洞：同一规范化型号存在真实拒绝/未解析的 `chip_model` 复核时，不能凭厂商等其他字段单独通过确认该实体。保留冲突与决定版本，不计新实体、不解除等待。
- 后端请求协议升为 5，身份策略升为 3；旧实体策略运行需新建隔离运行，未静默迁移。候选和复核 JSON Schema 均保持原样，严格校验未放宽。
