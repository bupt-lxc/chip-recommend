# 搜索服务配置与小规模复验

2026-10-10，按用户授权配置 Tavily、Firecrawl，并与已部署 SearXNG 对照。**配置和测试仅在独立验证环境完成，没有切换项目主搜索来源，没有正式数据库写入或 heartbeat 启用。**

## 实际配置

服务器验证目录：`/home/ubuntu/aishperf-search/provider-validation/`，分别建立 `tavily`、`firecrawl`、`searxng` 三个 Hermes 配置目录。前两者设置对应 `web.search_backend` 和 `web.extract_backend`；SearXNG 设置搜索后端与本机服务 URL。密钥仅保存在服务器 `.env`，目录权限 `0700`，文件权限 `0600`，报告及代码不包含密钥。通过 `HERMES_HOME` 选择验证目录，不改 `/root/.hermes` 正式配置。

已安装 Hermes 0.19 的三个后端均注册成功、支持搜索且配置检查 available=true。随后直接调用其真实 `web_search_tool`，不是仅使用外部搜索工具或伪造返回。

## 搜索复验结果

每个来源使用同样 4 条查询，每条最多 5 个结果；共 12 次原生搜索调用。Tavily 和 Firecrawl 各记录 4 次 API 请求，无重复重试。SearXNG 记录 4 次本地接口请求，上游实际请求不在此 API 请求计数内。

| 查询意图 | Tavily | Firecrawl | SearXNG |
|---|---|---|---|
| 中文开放发现：国产 AI 芯片 新品 发布 | 5 条，含具体芯片发布线索和行业媒体 | 5 条，含 DF1000 发布稿，但混有疑似垃圾站 | 0 条，上游验证码/超时 |
| 英文开放发现：new AI accelerator chip launch | 5 条，含 NVIDIA、Intel 官方发布和具体型号 | 5 条，含同类官方发布 | 0 条，上游异常 |
| 消费级训练：消费级 显卡 模型训练 支持 | 5 条，有 RTX 型号与微调/训练资料线索 | 5 条，但训练型号证据不足、混有推理资料 | 0 条，上游异常 |
| 已知型号控制：NVIDIA L40S official specifications | 5 条，包含 NVIDIA 官方 L40S 页面 | 5 条，官方 L40S 排首位，但另混入 L40 | 0 条，上游异常 |

Tavily 单次约 **1.8–2.7 秒**；Firecrawl 约 **5.2–23.3 秒**。两个来源均响应了开放发现意图，明显优于此前泛词/词典结果，但不代表来源独立或事实正确。消费显卡训练结论仅达到候选线索层面，不能将推理支持等同训练支持。L40 与 L40S 必须分别处理。

SearXNG 原生工具仍将 HTTP 200 / 空列表标为 success=true；本轮额外记录上游诊断，避免将这个标记当作搜索有效。百度验证码、Google/Brave 超时及共享暂停状态使本轮没有形成可判读的相关性样本。

## 原页面正文验证

对同样 3 个公开页面调用真实异步 `web_extract_tool`：DF1000 发布稿、火山引擎消费卡训练资料、NVIDIA L40S 官方页。

- **Tavily：3/3 取得非空正文，整批约 3.8 秒。** 分别取得约 11,514、7,780、14,972 字符，并在相应正文中找到型号线索。
- **Firecrawl：2/3 取得正文，整批约 131 秒。** 消费卡资料页报告 60 秒超时；另外两页取得正文。

正文存在及出现型号不等于字段校验通过；本轮未运行芯片字段提取、独立事实复核、数据库实体比对或六域完整验收。

## 结论

小样本支持 **Tavily 作为后续集成验证的首选搜索及普通正文提取来源；Firecrawl 按需备用；SearXNG 当前不作为可用主来源**。没有自动切换正式流程。GPT-6 Luna 独立审阅搜索结果，确认中英文开放发现得到相关候选，消费级训练证据仍弱，已知型号追查不能计入开放发现通过数。

这是一轮固定查询、单一时段的小样本，不证明长期稳定性、完整召回或字段准确性。接回项目之前仍需处理搜索来源与配额、消费级显卡筛选口径、超时/失败诊断以及证据快照衔接。

最终核验：正式容器镜像与启动时间保持不变；SearXNG 运行中、无 OOM、无重启。服务器保留脱敏 `search-validation-20261010-*.json`、`page-validation-20261010-*.json` 和 `verification-20261010.json`；本机证据在工作树 `.tmp/`。
