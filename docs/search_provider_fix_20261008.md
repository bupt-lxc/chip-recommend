# 搜索结果偏离目标问题与修复

## 原因与证据

旧运行 `20260930-103344-228dae98` 的目标为 NVIDIA H100 / 基础参数 / `vram_gb`。
Hermes 生成 10 条搜索词，工具得到 90 条搜索记录，去重后访问 80 个页面。
90 条记录全部来自 `bing-html`；标题和摘要中没有一条包含 NVIDIA、H100 或 HBM3，
实际内容涉及抖音、音乐软件和企业查询。Hermes 拒绝这些页面符合现有 Skill。

搜索工具的问题是仅用非空列表判断搜索源可用，没有识别返回内容是否已经偏离搜索目标。
这导致 Bing 的错误结果阻止了 DuckDuckGo 回退，且备用源异常没有保留到运行记录。

2026-10-08 在同一服务器探测发现，Bing 回显的搜索词与请求一致，但部分多词查询退化为
NVIDIA 首页、驱动等宽泛结果；带引号的 H100 查询能够返回相关页面。360 能返回 H100
规格页，DuckDuckGo 访问失败。现有证据不能确定 Bing 内部为何发生这种退化。

## 实际改动

- 检索词包含明确型号代码时，检查一批结果是否至少有一个标题、摘要或 URL 对应该型号。
  全批不匹配时记录搜索源失败，继续备用源。H100 不会匹配为 H1000；HBM3、FP16、80GB 等
  技术参数不充当型号代码。型号匹配兼容连字符、下划线与空格，同时区分 MLU370-S4 和 S8。
- 执行搜索词中的 `site:` 和 `-site:` 域名/路径约束，核对真实主机名，拒绝域名伪匹配。
- 没有型号代码的开放发现查询保持原有范围。健康批次中的页面保留给 Hermes 逐页判断，
  不由工具替代 Skill 决定字段价值。
- 各搜索源的结果和异常写入隔离运行的 `events.jsonl`，包含搜索词、来源、状态和原因。
- Skill、三个工具的调用顺序和后续字段提取合同保持一致。
